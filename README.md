## Overview

This project implements an end-to-end MLOps workflow, including:

- Data preprocessing pipeline
- Feature engineering
- Model training and evaluation
- Hyperparameter tuning
- Model versioning and export
- Deployment-ready prediction function

## Model

- HistGradientBoostingClassifier
- Pipeline & ColumnTransformer
- Probability Calibration
- Threshold Optimization

## Objective

Identify users at risk of subscription downgrade to support customer retention strategies.
